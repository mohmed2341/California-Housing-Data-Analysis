# California Housing Data Analysis

## Overview

This project presents an end-to-end data analysis workflow using the California Housing dataset. The project focuses on data cleaning, exploratory data analysis (EDA), feature engineering, feature selection, and machine learning preparation.

## Dataset

California Housing Dataset

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow

- Data Cleaning
- Missing Value Handling
- Outlier Detection
- Exploratory Data Analysis (EDA)
- Correlation Analysis
- Feature Engineering
- PCA
- Lasso Feature Selection
- Recursive Feature Elimination (RFE)

## Results

- Cleaned and prepared the dataset.
- Identified relationships between variables.
- Applied feature selection techniques.
- Generated visual insights using Python.

## Repository

The Jupyter Notebook contains the complete workflow from preprocessing to visualization.
